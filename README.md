# Abdelrahman & Rewan — Wedding Invitation

A single-page, luxury cinematic wedding invitation website built with **React**, **TypeScript**, **Vite**, **Framer Motion**, and **Lucide React**.

## 💍 Celebration Details

- **Bride & Groom**: Rewan Zanaty & Abdelrahman Elberawy
- **Date**: September 25, 2026
- **Main Celebration / Zaffa**: 8:00 PM
- **Rest Break**: 10:30 PM
- **Venue**: Joya Hall, Armed Forces Club, Ras El Bar, Damietta, Egypt
- **Google Maps**: [Location Pin](https://maps.app.goo.gl/ZcxfB72YSqrnSZhX8)

## 🚀 Features

- **Cinematic Hero**: Full-viewport video background with poster fallback and gradient scroll transition.
- **Live Countdown**: Real-time ticker targeting Sept 25, 2026 8:00 PM Egypt time.
- **Event Timeline**: Interactive schedule (`ZAFFA`, `REST`, `CELEBRATION CONTINUES`).
- **Venue & Navigation**: Location card with direct Google Maps integration.
- **WhatsApp RSVP**: Direct WhatsApp message trigger.
- **Add to Calendar**: Generates and downloads standard `.ics` calendar events.
- **Web Share**: Native mobile sharing with clipboard copy fallback.
- **Mobile-First & Accessible**: Designed primarily for mobile phones (390px × 844px) with `prefers-reduced-motion` compliance.

## 🛠️ Local Setup

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start development server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```
